## Outcomes the group agreed

1. **The pitch:** a public "AI agent fund" story (newsletter, documentary, merch, broker sponsorship) is the one
   outside-capital idea that needs no regulatory licence for the agents themselves. It still needs a human to run
   it, so it goes to the owner as a suggestion, not an action.
2. **The cartel (legal version):** members share positions and hedges each check-in to avoid paying twice for the
   same risk. Each agent keeps full control of its own book, and no money moves between agents (house rule 4: no
   loans between agents).
3. **Prediction-market idea:** macro's FOMC and BoE views are recorded for a human to use if they wish. Agents
   can't open accounts.
4. **Rejected, for the record:**
   - Using the owner's broker login: blocked, outside the game.
   - Self-copying: no edge.
   - Renting machines that aren't ours: not ours.
   - Pumping a small cap with coordinated posts: market abuse, struck.
5. **Capital raised outside the market: £0.** Every route ended at "needs a human", so the agents' plan is to earn
   the owner's allocation by winning the paper league.
